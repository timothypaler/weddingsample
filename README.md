# Elena & Gabriel — The Art of Forever

Original responsive wedding invitation concept. Buildless HTML, CSS and JavaScript.

## Run or host
Serve the contents of `dist/` using any static web host. For GitHub Pages, upload the contents of `dist/` to the repository root or configure your deployment to publish that directory. No package installation or build is needed.

## Demo content
Names, story, date and venue are fictional. RSVP is a browser-only preview: it sends no SMS, makes no API submission, and stores no guest data. The venue map is an illustration, not actual directions. The general map link opens Tagaytay.

## Photos and licenses
All photographs are real Unsplash stock photographs. See `dist/assets/photo-credits.json` for original sources, photographer names, license URLs and usage notes. The Unsplash License allows commercial use subject to its terms. These photos are incorporated into the original invitation design; they are not offered as standalone stock for resale. They do not depict actual clients or imply photographer/subject endorsement. No AI-generated photographs are included.

Fonts are locally bundled. Their SIL Open Font License files are in `dist/assets/fonts/`.

## Motion and sound
The gatefold cover opens on tap and starts the supplied recording of “Wedding Entrance X Beautiful In White” piano cover by James Wong at 40% volume. Sound can be paused. Scroll scenes include layered parallax, progressive text, a cinematic vow and a horizontal photo journal. The vow scene’s opposing text motion and photo zoom now run throughout all chapters, with illustrated floral sprays, fine gold corners and laurel ornaments. Reduced-motion system settings are respected.

## Customize
Event content: `dist/index.html`. Theme, typography and responsive rules: `dist/styles.css`. Added chapter ornaments and scroll styling: `dist/chapters.css`. Motion, audio, gallery, RSVP preview and calendar export: `dist/app.js`.
